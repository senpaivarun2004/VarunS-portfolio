## 🌟 Overview

Welcome to the personal developer & data science portfolio of **Varun S**. Designed with a high-performance, dark-mode aesthetic inspired by developer-first platforms like Vercel, styled using **Tailwind CSS v4**, and driven by **Astro.js v6** static generation with reactive **React 19** client islands.

- **Motion & Dynamics:** [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://greensock.com/gsap/) micro-interactions.
- **Visual Cursor:** Sparkle particle physics canvas engine following user motion.
- **Form Delivery:** [Web3Forms](https://web3forms.com) async dispatch with client-side anti-spam validation.

## ✉️ Live Contact Form & Web3Forms Integration

The portfolio includes an asynchronous, spam-protected contact form powered by **Web3Forms**:

```
┌──────────────┐     POST (JSON)     ┌──────────────┐     Delivery     ┌────────────────────────┐
│ Visitor Form │ ──────────────────▶ │  Web3Forms   │ ───────────────▶ │ senpaivarun@gamil.com  │
│  Validation  │   (HTTPS API)       │ Spam Filter  │   (Inbox)        │                        │
└──────────────┘                     └──────────────┘                  └────────────────────────┘
```

- **Features:**
  - ⚡ Real-time client validation (Name, Email format, Subject, Message).
  - 🔄 Dynamic button status (`Sending...` + spinner) preventing duplicate clicks.
  - 🛡️ Built-in honeypot bot trap (`botcheck`).
  - 🔒 Zero exposed secrets (configured via `PUBLIC_WEB3FORMS_KEY`).

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/senpaivarun2004/VarunS-portfolio.git
cd VarunS-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables
Copy [.env.example](file:///c:/Users/senpq/Projects/GitHub/VarunS-portfolio/.env.example) to `.env`:
```bash
cp .env.example .env
```
Add your Web3Forms access key:
```env
PUBLIC_WEB3FORMS_KEY=your_access_key_here
```

### 4. Launch development server
```bash
npm run dev
```
Visit `http://localhost:4321` in your browser.
